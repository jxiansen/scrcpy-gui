## 统一设计 token（系统级修正）

| 角色 | 字号 / 字重 |
|---|---|
| 说明、meta、placeholder | 11 / 400，`#78716C` |
| 正文、标签、输入 | 12.5 / 400–500 |
| 卡片 / 小节标题 | 13.5 / 600 |
| Tab 标签 | 12 / 600 |
| 键帽 | 11 / 500 |
| 页脚标题 | 13 / 600 |
| Logo / CTA | 30 / 22（保持） |

- 图标统一 16px / stroke 1.5；控件高度：输入 36、tab 44、开关行 28。
- 间距只允许 4 / 8 / 12 / 16 / 24。
- tracking 只用于 ≤11px 的大写拉丁字母。
- 选择器边框：浅色 `#d9d5e6`、深色 `#2e2e36`；chevron 12px；深色填充用 `#17171a`，不要纯黑（避免「洞」感）。

### 主题专项

- **浅色**：控制台太黑、成为第二视觉焦点；卡片与页面色差仅 5 级，靠边框撑分离；选中「浅色」pill 白底白字、白色强调色圆点消失 → 需 violet tint + 1px 圆环。
- **深色**：muted 文字（OTG 描述、快捷键标签、mDNS 地址、页脚链接）对比度不足；控制台 `#09090c` 比页面 `#0c0b11` 还黑，变成 void；黑色强调色圆点消失。建议页面 `#08080a` / 卡片 `#141417` / 边框 `#26262c`，muted 提亮一级。
- 两套主题都要修控制台 header/body 缩进。
